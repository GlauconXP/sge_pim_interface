# Arquivos históricos (não utilizados pelo sistema atual)

Esta pasta preserva arquivos de etapas anteriores e instruções antigas. Eles foram mantidos como referência, mas não devem ser usados para compilar ou executar o SGE atual.

## Código ativo
- Servidor principal: `backend/src/server.c`
- Biblioteca HTTP usada na compilação: `backend/third_party/mongoose/mongoose.c` e `mongoose.h`
- Interface ativa: `frontend/index.html`, `frontend/style.css` e `frontend/script.js`
- Instruções válidas: `README.md` na raiz e a documentação atual em `docs/`

O servidor antigo em `server_antigo.c`, `script_anterior.js` e `script_copy_antigo.js` são apenas cópias para consulta. As pastas `instrucoes_antigas/` contêm notas de instalação de versões intermediárias, algumas com caminhos e informações que já não correspondem à versão atual.
