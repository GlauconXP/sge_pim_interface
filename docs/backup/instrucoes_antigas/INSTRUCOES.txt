SGE — Cadastro e edição de funcionários

Arquivos incluídos na atualização:
- backend/src/server.c: endpoints GET/POST/PUT para funcionários.
- frontend/script.js: formulário, edição, ativação/inativação e recarga dos dados.
- frontend/index.html: ações na tabela e modal de funcionário.
- frontend/style.css: estilos do modal e dos botões de ação.

Como instalar:
1. Faça uma cópia de segurança da pasta atual do projeto.
2. Extraia os arquivos deste pacote na raiz do repositório sge_pim_interface, permitindo substituir os arquivos correspondentes.
3. Pare o servidor C com Ctrl+C.
4. Abra o PowerShell na raiz do projeto e compile:
   gcc -D_POSIX_C_SOURCE=200000L .\backend\src\server.c .\backend\third_party\mongoose\mongoose.c -I.\backend\third_party\mongoose -o .\build\sge_server.exe -lws2_32 -lodbc32
5. Se a compilação terminar sem erros, execute:
   .\build\sge_server.exe
6. Abra http://127.0.0.1:8000 e pressione Ctrl+F5.

Teste sugerido:
- Em Funcionários, clique Novo funcionário e cadastre uma matrícula de teste ainda não utilizada.
- Confira se aparece na tabela após salvar e atualizar a página.
- Clique Editar, altere setor/cargo e salve.
- Use Inativar/Ativar para alterar a situação sem excluir o registro.
- Confira que funcionários inativos deixam de aparecer no seletor de responsável ao cadastrar encomenda.

A API utiliza consultas parametrizadas. Não exclui funcionários; a situação é alterada pelo campo Ativo, preservando vínculos históricos.
A autenticação atual do protótipo continua sendo demonstrativa; este cadastro não substitui um sistema real de permissões.
